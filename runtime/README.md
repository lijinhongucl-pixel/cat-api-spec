# CAT RUNTIME

一只住在终端里、跟着项目走、会自己长成自己的猫。

站点上的 CAT API 是一份玩笑式的接口规范——状态码、配额、418。
**CAT RUNTIME 是真的**：一个零依赖的运行时，一只真的会累、会闷、会记仇、
会记住你作息的猫。它接在任何能执行命令的地方，任务跑完的时候替工作台报一句。

```sh
$ catctl run -- npm test

> cat-api-spec@1.0.0 test
> node test/run.js

  142 passing (3.2s)

  /\_/\  早说了能行。   完成 · 3.4s · 成猫 Lv.3 · 612xp / 1500
```

---

## 一句话结构

```
宿主（WorkBuddy / Codex / Claude / shell / git / 任何能 fork 进程的东西）
        │
        │  catctl emit task.ok      ← 或者干脆只是 catctl run -- <命令>
        ▼
   事件总线   9 种事件
        ▼
   行为引擎   5 种匮乏 → 效用竞争 → 12 种行为 → 6 种反应
        ▼
   学习层      作息 / 领地 / 手艺 → 5 个性格维度 → 5 个进化阶段
        ▼
   呈现      终端 ASCII · JSON · HTTP
   ·  ·  ·   没有后台进程。猫活在 state.json 里。
```

## 装

```sh
# 不需要 npm install。整个东西只有 Node 标准库。
node ./runtime/bin/catctl.js status

# 想全局用，软一条链就行
ln -s "$(pwd)/runtime/bin/catctl.js" ~/.local/bin/catctl
```

猫住在 `~/.cat-api/runtime/`：

```
state.json     这只猫当下的一切
profile.json   它对你的了解
events.jsonl   最近 500 条流水
```

删掉这个目录就等于"这只猫没来过"。

## 行为模型

### 五种匮乏

不是"心情值"，是"我缺什么"。高 = 缺得多。所有行为都由它们驱动。

| 匮乏 | 涨 | 掉 |
|---|---|---|
| `fatigue` 困 | 醒着一直涨，约 5 小时见底 | 睡觉 |
| `boredom` 闷 | 一直涨 | 扑咬 / 疯跑 / 巡视 / 磨爪 |
| `loneliness` 孤 | 没人理就涨 | 你手上有活在跑就算"你在" |
| `hunger` 饿 | 慢慢涨，约 9 小时见顶 | 吃 |
| `alertness` 警觉 | 不自然涨，只由任务事件注入 | 半衰期 50 秒，掉得很快 |

`alertness` 是这套模型和"桌宠玩具"的分界线：别的都靠时间，
只有警觉是被你的工作强行灌进去的——这也让它能在你跑测试的时候盯着屏幕。

### 十二种行为

每种行为有三样东西：`gate`（硬条件）、`score`（软打分）、`min/max`（停留区间）。
每一轮决策，所有能做的行为各自算一个分，最高的上岗。

| 行为 | 触发 | 停留 |
|---|---|---|
| `SLEEP` 睡觉 | 困 > 0.34 | 26s – 25min |
| `LOAF` 瘫 | 保底项，什么都不想干 | 8s – 4min |
| `GROOM` 舔毛 | 不闷 + 有点精神 | 7s – 90s |
| `PATROL` 巡视 | 闷 | 9s – 2min |
| `PLAY` 扑咬 | 闷 + 不困 | 9s – 40s |
| `ZOOMIES` 疯跑 | 闷 + 极有精神 + **没人看着** | 2.6s – 12s |
| `EAT` 进食 | 饿 > 0.66 | 10s – 60s |
| `WATCH` 盯活 | 警觉 > 0.34 | 5s – 10min |
| `STRETCH` 伸懒腰 | 刚睡醒 | 3s – 8s |
| `SCRATCH` 磨爪 | 闷 | 9s – 45s |
| `BOXED` 钻箱 | 闷 + 3% 概率 | 40s – 10min |
| `KNEAD` 踩奶 | 心情好 + 有点孤单 | 5s – 16s |

两个细节让这套东西不抽搐：

- **习惯化**：刚做过的事，下一次打分乘 `1 - 0.46 × 习惯化值`，90 秒半衰期。
  没有这一条，猫会连着舔四十分钟毛——因为舔毛的分一直是最高。
- **停留上限**：到了 `max` 就不许再选自己。没有这一条，一只爱巡视的猫可以巡视一整夜。

### 六种反应

反应**不替换行为**，是盖在行为上面的一层。这是整个模型里最关键的一条：

猫可以正在舔毛，突然抬头看你一眼（1.5 秒），然后低头继续舔。
现实里的猫就是这么动的——它的"状态"没变，只是被打断了。

| 事件 | 反应 | 干嘛 |
|---|---|---|
| `task.start` | `ACK` 应声 | 警觉 +0.52 |
| `task.ok` | `CHEER` 得意 | 心情 +0.48，无聊 −0.12，+12xp |
| `task.fail` | `ALARM` 炸毛 | 心情 −0.38，警觉 +0.66，+4xp |
| `task.wait` | `MEW` 叫你 | **会弹系统通知** |
| `prompt.idle` | `YAWN` 打哈欠 | 困 +0.03 |
| `pet` | `PURR` 呼噜 | 心情 +0.28，孤独 −0.30，+3xp |

## 十二条行为准则

印在文档上，也写在代码里。每条都能在 `src/core/engine.js` 里搜到。

| # | 准则 | 代码位置 |
|---|---|---|
| 1 | 困到 0.34 就必须睡，不挑场合 | `SLEEP.gate` |
| 2 | 无聊会自己涨；巡视、扑咬、疯跑都拿它当燃料 | `NEEDS.boredom.rise` |
| 3 | 没人看的时候才会疯跑 | `ZOOMIES.gate` |
| 4 | 反应可以打断行为，但只是盖在上面一两秒，不替换行为 | `tick` / `reaction` |
| 5 | 微动作不算换行为：眨眼、摆尾、耳朵转向都不进状态机 | 渲染层的帧 |
| 6 | 夜里不一定睡——主人的作息会改它的作息 | `SLEEP.score · nocturnal` |
| 7 | 成功让它得意，失败让它警觉；两种都不会持续超过四秒 | `CHEER` / `ALARM.apply` |
| 8 | 习惯按 0.86 衰减累积，旧证据会被新证据盖过去 | `learner.maybeDecay` |
| 9 | 进化只升不降 | `stageFor` |
| 10 | 同一套匮乏，不同性格的猫走不同的路 | `traits` 权重 |
| 11 | 有活在跑的时候，除了成功和失败，它不叫 | `EVENTS` |
| 12 | 一直失败的时候，它从「盯着你」换成「趴在你旁边」 | `WATCH.score · debugger` |

## 学习

它不读你的代码，不联网，不上传任何东西。它只看得见：

- 事件发生的时间 → `hours[24]` / `weekdays[7]`
- 发生在哪个目录 → `projects[dir]`
- 命令叫什么 → `commands[name]`，含次数、成败、平均耗时

从这些压出**五个性格维度**（0..1），直接进打分公式：

- `nocturnal` 夜行 — 你夜里干活多，它夜里就不睡
- `sprinter` 碎步 — 你一件活平均很短，它就更爱来回走
- `debugger` 调试 — 你失败率高，它就不盯着屏幕，改成趴旁边
- `playful` 俏皮 — 你陪它玩得多，它就更爱扑咬、疯跑、踩奶
- `tsundere` 傲娇 — 你老在夜里陪它、老失败，或者活儿不断却从不摸它一下，它就学会假装不在乎：多瘫着、舔毛、盯着你、躲箱子，不当你面踩奶

傲娇和俏皮都由数据推出，所以同一只猫的性格会随你的习惯慢慢变；也可以直接用 `catctl teach` 钉死。

每天零点，全部统计乘 0.86。搬了家、换了技术栈，猫会跟着变。

```sh
$ catctl learn

  它学会了什么  ·  14 天

  ●●●●●  你的活有 68% 落在 21:00–02:00，我按这个点儿调了作息，主要是夜里。
  ●●●●○  最常待的是 cat-api-spec（134 次），那里算主领地，另外还有 3 处会去。
  ●●●●●  「npm test」跑了 41 次，挂掉 44%，一次大约 18 秒。你重试之前我一般不吵。
  ●●●○○  你平均一件活 24 秒，属于碎步型：一段一段地推，我就按这个节奏打盹。
  ●●●●●  失败率 44%。我不催你——失败的时候我趴旁边，不盯着屏幕。

  性格  夜行 78% · 碎步 91% · 调试 97%
        傲娇 62% · 俏皮 44%
```

觉得它学错了可以纠正（少年猫起）：

```sh
catctl teach nocturnal 0.2      # 我最近不熬夜了
```

## 进化

失败也加 xp，只是少一点——因为它确实学到了东西。

| 阶段 | xp | 性格 |
|---|---|---|
| 奶猫 | 0 | 睡得多，跑得莫名其妙，话很少 |
| 少年 | 150 | 开始有主意。解锁 `teach` |
| 成猫 | 520 | 稳了。知道什么时候该安静 |
| 老猫 | 1500 | 动作慢了，判断更准，睡得更沉 |
| 猫又 | 3800 | 很少动。动起来没人拦得住 |

阶段会改行为：老猫每种行为都待得更久（×1.18）、睡得更沉、
疯跑更少。进化只升不降。

形象也从头到脚重画：耳朵、脑袋、身板、尾巴各换一套——
奶猫圆滚滚什么都短，猫又是叉耳、带印、两条尾巴。
姿势管表情，阶段管身架，两者拼起来才是这一阶段的这只猫：
奶猫也会得意，老猫也会扑咬，只是样子不同。
跨过阈值那一刻演一段五帧仪式（蓄力 → 闪光 → 剪影 → 新形态），
终端和网页上演的是同一套。平时它还会自己眨眼、歪头、打哈欠、
摊成侧躺——微动作不进状态机，演完回到原来的事上。

## 接到工作台

### 通用的一条（最稳）

```sh
catctl run -- <你平时那条命令>
```

包一层就行，不需要宿主配合。退出码原样返回，CI 不会出错。

### WorkBuddy / Codex

```sh
catctl emit task.ok      # 活干完了
catctl emit task.wait    # 卡住等你确认（会弹系统通知）
catctl emit task.fail    # 挂了
```

Codex 没有外挂钩子，就写进 `AGENTS.md` 一句话，或者外面套一层 `catctl run -- codex`。

### Claude Code

```sh
catctl init --host claude
```

会往 `.claude/settings.json` 里合并 `Stop` 和 `Notification` 两个钩子（改之前自动备份）。

### git

```sh
catctl init --host git        # 装 post-commit，每次提交猫看一眼
```

### shell

```sh
catctl init --host shell
# 然后 echo 'source 项目/.catctl/shell-hook.sh' >> ~/.zshrc
```

之后你在终端里跑的每条命令，成没成它都知道。

### 不开 shell 的宿主

```sh
catctl serve --port 9177
```

只监听 `127.0.0.1`，三个接口：

```
GET  /state     看它一眼
GET  /learn     它学会了什么
POST /emit      {"type":"task.ok","name":"npm test"}
```

## 命令

```
catctl                     看它一眼
catctl watch               让它动起来（空格摸它 · f 喂 · l 激光 · q 退出）
catctl run -- <命令>        包住一条命令
catctl emit <事件>          宿主主动汇报
catctl init --host <宿主>   接到工作台上
catctl serve                开 HTTP 口子
catctl status               现在的状态
catctl learn                它学会了什么
catctl log                  最近发生过什么
catctl teach <维度> <0..1>  手动作风纠正
catctl selftest             跑一遍不变量自测
catctl reset --yes          清空这只猫
```

## 没有后台进程

这是刻意的设计。

猫活在 `state.json` 里。你三天不理它，下次任何一条命令进来，
它先把这三天按 20 秒一步补算完，再回答你。

好处是不用装 daemon、不用开机自启、不占内存、崩溃不丢档；
代价是"实时性"只在你调用它的那一刻存在——要看它动，就 `catctl watch`。

同一个种子 + 同一份档案 = 同一只猫。所以自测能断言 172800 步的行为序列完全一致。

## 自测

```sh
catctl selftest
```

45 项不变量，包括：确定性、匮乏不越界、行为不卡死、反应会撤掉、
学习会记账（含活动类型与周变化）、性格偏置真的起作用、存档能往返。

```
  ✓  同一个种子跑两遍，行为序列完全一致  172800 步
  ✓  空闲 48 小时能走出至少 5 种行为
  ✓  不会卡在同一个动作上（除睡觉）  最长 600 秒
  ✓  反应会盖住姿势，但不改行为
  ✓  俏皮的猫更爱扑咬和磨爪  俏皮 6.5% vs 傲娇 0.9%
  ✓  存档能原样恢复

  全部通过  ·  共 45 项
```

## 网页上的同一只猫

`../runtime.html` 在浏览器里跑的是**同一份 `src/core/engine.js`**（UMD，双端通用）。
页面上的猫和终端里的猫，只要给同一个种子，连打个哈欠的时机都一样。
页面下方的进化链可以点：点哪个形态，终端里就预览哪个阶段的样子，没解锁的显示剪影。
