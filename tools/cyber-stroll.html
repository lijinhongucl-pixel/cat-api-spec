TOOL / CYBER STROLL

赛博遛猫

对应规范 §8 外设总线 · 分类 PER/LEASH「牵引与项圈」· 约束器

把一张图片降格成一只网格化的「猫」，然后用鼠标指针当牵引绳去遛它。 最终产物是两张可下载的 SVG 文件——一张静态、一张带 SMIL 循环。

管线四步：像素 → 网格 → 部件 → 路径。 牵引绳长 2.03 体长（附录 R 排除伸缩配置），不可调。 全程离线——图片不离开本机，不发送任何网络请求。

已知限制

  1. 部件切分粗粒度：只用包围盒，无骨架估计；摆幅到极限时接缝可见。
  2. 默认 64 格降采样：细长的尾巴尖、耳朵尖端、胡须会先消失。
  3. 背景剔除单阈值：纯色背景最省事，杂背景调不干净——可以勾「反转掩膜」试试。
  4. 不处理多主体：两只猫会被合成一只。
  5. 朝向是启发式：遮挡、卷成团、短尾会判断反，用「镜像朝向」按钮手动翻。
  6. 速度是比例量：图里没有绝对尺度，所有绳长、步幅、距离都按同一比例折算。
所有数值标注为 HEURISTIC——本页没有一条数值来自公开信源， 遵循「没有出处就标 HEURISTIC」的纪律。 本页离线运行，图片不离开本机，导出 SVG 时也不上传任何数据。 「从星图接入接图」通过 sessionStorage 在同一标签页内一次性交接，读完即删。
