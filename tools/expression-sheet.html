CAT API §10 · 表情联系表

表情联系表14 状态 · 13 维参数 · 24×24 网格

每格是一帧的确定性渲染结果。带橙边的 PAIN 没有专属参数—— 它的向量与健康基线几乎逐位相同，因为表情系统工作正常，只是内容与事实不符。 猫在疼痛时仍会看起来放松，这才是架构级缺陷。鼠标移上去可以看清它与基线差在哪一行。

由 assets/js/expression.js 生成。渲染内核零依赖，浏览器与 Node 双用。
规格正文见 CAT API §10 表情接口定义。 可单独打开 表情渲染器 拖滑块改 13 维参数实时看效果。
