接入 CrossPet Protocol

让你的网站也支持宠物串门。只需加载一个脚本并初始化：

<script src="assets/js/crosspet.js"></script>
<script>
  CrossPet.init({
    petType: 'dog',          // 'cat' | 'dog' | 'hamster' | 自定义
    petName: '马文的狗',
    petSVG: '<svg>...</svg>',  // 你的宠物 SVG
    onPetLeave: function(dir) {
      // 你的宠物走出屏幕时触发
      console.log('我的狗往', dir, '走了');
    },
    onPetArrive: function(visitor) {
      // 收到别站宠物时触发
      console.log(visitor.petName, '来了');
    },
    onPetMeet: function(myPet, visitor, interaction) {
      // 两只宠物相遇时触发
      console.log(myPet.name, '和', visitor.name, interaction);
    }
  });
</script>

要启用真正的跨站实时通信，需要配置 Supabase：

CrossPet.configure('https://your-project.supabase.co', 'your-anon-key');

没有配置 Supabase？没关系，演示模式会每 60-180 秒自动模拟一次随机串门。
