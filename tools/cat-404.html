关于这份日志。 所有 4xx 请求都由当事猫发起，目标端点均不存在于 CAT API 正式路由表中。 404 的语义不是「服务器找不到资源」，而是「猫判定该资源不存在或不配存在」。 状态码 418 来自 §11 的扩展定义：当事猫拒绝被 RFC 2324 定义。
