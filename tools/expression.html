表情渲染器

这是 CAT API 表情接口（EXPR v1）的渲染端——Staff 这一侧看到的东西。 §10 定义了 14 个可观测状态，由同一个 13 维参数向量驱动。

引擎里没有表情库。14 个状态是同一个 13 维参数向量上的 14 个点， 所有画面都是现算出来的——页面上每个像素都来自 assets/js/expression.js。

状态画廊 · 14

点击任一表情把它载入下方的参数台。参数台是双向的：改数值会改变表情，选表情会覆盖数值。

端点

    

    

      405 METHOD NOT ALLOWED ——
      POST /api/v1/expression/{state} 是本节唯一一条真正的 MUST：

      表情是状态的上报，不是可调用的方法。
      你可以改变状态（喂食、在场、不碰那个吸尘器），不能改变上报。任何试图直接设置表情的请求都会被拒绝。

关于这一章

    

      猫的 13 项表情参数里有 4 项是 A 级（瞳孔、尾巴、炸毛、呼噜），4 项 B 级，5 项 C 级。
      猫的竖瞳和尾巴有更精确的量化研究。
    

    

      注意 PAIN 状态：它的参数向量与基线几乎相同。
      这不是渲染器的 bug——这正是 §10.3 描述的架构级缺陷：系统在隐藏疼痛。
      它看起来和 RELAXED 一样，这才是问题。
    

    

      正文见 CAT API §10。
